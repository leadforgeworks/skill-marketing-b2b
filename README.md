# Marketing B2B : skill Claude Code

Positionnement, personas, choix des canaux, ligne éditoriale, plan de contenu 30 jours et aimants à prospects, reliés à des rendez-vous commerciaux.

**Ce que vous obtenez :**
- Votre positionnement en une phrase et vos 2 personas
- Les 2 canaux à prioriser selon votre cible et votre temps
- Un plan de contenu de 30 jours et 3 idées d'aimant à prospects

Un skill gratuit pour [Claude Code](https://claude.com/claude-code), en français, pensé pour les dirigeants de TPE et PME, les indépendants, les commerciaux et les agences.

## Installation

**macOS / Linux**
```bash
git clone https://github.com/leadforgeworks/skill-marketing-b2b ~/.claude/skills/marketing-b2b
```

**Windows (PowerShell)**
```powershell
git clone https://github.com/leadforgeworks/skill-marketing-b2b "$HOME\.claude\skills\marketing-b2b"
```

Redémarrez Claude Code : le skill se déclenche tout seul quand votre demande correspond. Pour le mettre à jour : `git pull` dans ce dossier.

## Ce que ce skill ne peut pas faire seul
Claude réfléchit et rédige, mais il n'a ni base d'entreprises, ni moyen de vérifier un email, ni boîte d'envoi, ni mémoire de vos prospects d'une conversation à l'autre. C'est ce que fait [LeadForge](https://leadforge.works) :
- trouver les entreprises dans le registre officiel et identifier leurs dirigeants ;
- trouver et **vérifier** les emails professionnels (pas de crédit dépensé si l'email n'est pas trouvé) ;
- envoyer depuis votre propre boîte, à un rythme humain, et s'arrêter dès qu'un prospect répond ;
- suivre chaque prospect jusqu'au devis signé (clics, visites, réponses, rendez-vous, relances).
